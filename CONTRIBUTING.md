# Cómo Contribuir / Contributing Guide

¡Gracias por querer contribuir a Marketing Cloud Arcade! 🕹️

## Proceso / Process

1. **Fork** el repositorio
2. Crea una rama: `git checkout -b feat/ssjs-mi-articulo`
3. Usa `article.html` como template base
4. Agrega tu artículo a `es/` y/o `en/`
5. Actualiza el catálogo en `catalog.html`
6. Abre un **Pull Request** con descripción clara

## Convenciones de commits / Commit conventions

```
feat(ssjs): nuevo artículo sobre HTTP requests
fix(ampscript): corrección en ejemplo LookupRows
docs: actualizar README
style: mejorar highlight de código
```

## Checklist de artículo / Article checklist

- [ ] Título descriptivo con categoría
- [ ] Nivel indicado (Beginner / Intermediate / Advanced)
- [ ] Al menos 2 bloques de código con botón copiar
- [ ] Un caso de uso real
- [ ] Tags relevantes
- [ ] Revisado ortográficamente

## Estilo de código / Code style

- Usa las clases de syntax highlighting ya definidas: `.kw`, `.fn`, `.st`, `.cm`, `.nb`, `.vr`
- Siempre incluye el lenguaje en `.code-block-lang`
- Comenta las partes clave del código

¡Gracias! / Thank you! 🎮
